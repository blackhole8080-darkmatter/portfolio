    03 Approach

    Three rules that show up
    in every repository.

    01

    Never fake a verdict.

    A missing answer is not a clean one. urlscan-mcp separates no data from no findings; DEEP records a timed-out source as degraded and returns unknown when nothing responds. Being useless is recoverable — being confidently wrong is not.

    02

    Local-first, by default.

    A board game parlour that needs a server is a rented game. Science Lab vendors three.js so it works offline; DEEP runs on Ollama with cloud models as a fallback. The network is an enhancement, never a dependency.

    03

    Boring cores, sharp edges.

    Parlour is one alpha-beta search behind seven pure-function game specs. Indra is vertical slices with provenance in every envelope. The interesting behaviour lives at the edge; the middle stays small enough to reason about.
